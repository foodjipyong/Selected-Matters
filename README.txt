[사용 안내 — 관리자용/사용자용 분리 + 엑셀 업로드 + 업무구분/분야 다중선택 버전]

1) 서버 배포
   이 폴더의 7개 파일(user.html, admin.html, db.json, pizzip.min.js, mammoth.browser.min.js,
   xlsx.full.min.js)을 모두 같은 폴더에 그대로 올려주세요.

2) 직원용 화면 — user.html
   실적 DB가 코드에 박혀있지 않고 같은 폴더의 db.json을 페이지를 열 때마다 새로 불러옵니다.
   분야가 2개 이상인 실적, 업무구분(소송/자문)이 지정된 실적도 정상적으로 검색·필터링됩니다.

3) 실적 DB 업데이트 — admin.html
   실적 추가/수정/삭제 후 "db.json 다운로드" 클릭 → 받은 파일을 서버의 기존 db.json에 덮어쓰기
   → 그 순간부터 직원들은 user.html을 새로고침만 하면 최신 실적으로 검색됩니다.
   (user.html을 다시 배포하거나 재회람할 필요가 전혀 없습니다)

   ▸ 엑셀로 불러오기: "엑셀 불러오기(표에서 수정)" 버튼으로 xlsx/xls 파일을 업로드하면 표로 불러와서
     추가 수정 후 저장할 수 있고, "엑셀 → db.json 즉시 변환" 버튼은 업로드 즉시 db.json으로
     변환해서 바로 다운로드까지 진행합니다. "엑셀 양식 받기"로 예시 파일을 받아 쓰면 편합니다.

   ▸ 업무구분(소송/자문): 표에 "구분" 열이 추가되어 각 실적을 소송/자문으로 지정할 수 있습니다.
     엑셀의 "구분" 열(값: 소송 또는 자문)을 그대로 인식합니다.

   ▸ 분야 다중선택: 표의 "분야" 열이 체크박스 방식으로 바뀌어, 실적 하나에 분야를 2개 이상
     선택할 수 있습니다. 엑셀에서는 분야 칸에 "건설행정, 건설환경"처럼 쉼표(,)나 슬래시(/)로
     구분해서 적으면 자동으로 여러 개가 체크된 상태로 불러와집니다. 가운데점(·) 등 기호나 공백
     차이는 무시하고 텍스트만 비교해서 8개 분야명과 자동으로 매칭됩니다.

   ▸ 기타 분류(user.html): 8개 표준 분야 중 어디에도 해당하지 않거나 분야가 아예 지정되지
     않은 실적은 직원용 검색 화면(user.html)에서 자동으로 "기타"로 분류되어, 왼쪽 분야
     체크박스에서 "기타"를 선택하면 확인할 수 있습니다.

4) 참고
   - pizzip/mammoth/xlsx 라이브러리는 전부 로컬 파일로 포함되어 있어 사내망이 외부 인터넷을
     차단해도 정상 동작합니다.
   - 기존 db.json(322건)은 분야가 1개씩만 있는 원본 그대로이며, 업무구분(type)은 비어 있는
     상태입니다. admin.html에서 필요에 따라 채워 넣고 다시 다운로드해서 덮어써 주세요.
   - user.html은 업무구분이 비어있는 항목에 대해서는 기존처럼 실적 내용을 분석해 소송/자문을
     자동 추정합니다(관리자가 직접 지정하면 그 값이 우선 적용됩니다).
