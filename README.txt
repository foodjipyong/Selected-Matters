[사용 안내 — 기존 파일을 관리자용/사용자용으로 분리한 버전]

1) 서버 배포
   이 폴더의 5개 파일(user.html, admin.html, db.json, pizzip.min.js, mammoth.browser.min.js)을
   같은 폴더에 그대로 올려주세요.

2) 직원용 화면 — user.html
   기존에 쓰시던 화면과 완전히 동일한 디자인/기능입니다. 다만 실적 DB가 코드에 박혀있지 않고
   같은 폴더의 db.json을 페이지를 열 때마다 새로 불러오도록 바뀌었습니다.

3) 실적 DB 업데이트 — admin.html
   실적 추가/수정/삭제 후 "db.json 다운로드" 클릭 → 받은 파일을 서버의 기존 db.json에 덮어쓰기
   → 그 순간부터 직원들은 user.html을 새로고침만 하면 최신 실적으로 검색됩니다.
   (user.html을 다시 배포하거나 재회람할 필요가 전혀 없습니다)

4) 참고
   - 기존 파일이 쓰던 pizzip/mammoth 외부 CDN(jsdelivr)을 로컬 파일로 바꿨습니다.
     사내망이 외부 인터넷을 차단해도 정상 동작합니다.
   - 현재 db.json에는 기존 파일에 있던 322건이 그대로 들어있습니다.
   - 기존 파일에 있던 "dbCount" 표시 관련 오류(존재하지 않는 요소를 참조하던 버그)를
     겸사겸사 고쳐서, 좌측 상단에 실제 DB 건수가 표시되도록 했습니다.
